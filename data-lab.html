How features are calculated
Each payment's history features use earlier observed transactions. Amount features use the current payment. Outcome labels remain separate and are excluded from feature calculations.
Graph topology uses payment attempts at strictly earlier timestamps. It excludes the current payment, other payments at the same timestamp, future identities, deposits and reports. Expand a graph feature to inspect its orientation, readout, method, parameters and approximation. PageRank error bounds and snapshot lag describe the global estimate; PPR error bounds describe each local estimate.
Statistics describe the full dataset and are for inspection; they are not fitted model preprocessing.
